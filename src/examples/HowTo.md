# Arquivos de exemplos de algoritmos

Para executar um dos exemplos, você pode usar os comandos:

Defina o caminho do PYTHONPATH para o diretório `src` e execute o script desejado:
```bash
export PYTHONPATH=./src
```
Em seguida é possível executar qualquer exemplo localizado na pasta `src/examples/`:

```bash
python src/examples/<example>.py
```

Exemplo:

```bash
export PYTHONPATH=./src
python src/examples/example_conversion.py
```
